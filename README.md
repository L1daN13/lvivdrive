# LvivDrive

Інтерактивна карта **парковок** і **електрозарядних станцій** Львова та околиць на основі відкритих даних OpenStreetMap.

- Карта Львова (Leaflet + OpenStreetMap) з кластеризацією маркерів
- Реальні об'єкти з OpenStreetMap через Overpass API — без вигаданих даних
- Пошук за назвою, вулицею, адресою чи оператором + пошук адрес у Львові (Nominatim)
- Фільтри: тип об'єкта, платні/безкоштовні, тип роз'єму, потужність, відстань, приватні об'єкти
- Картка об'єкта з усіма відомими полями й чесним «невідомо» для відсутніх
- Маршрут у Google Maps або OpenStreetMap
- «Вибране» без реєстрації (LocalStorage)
- Геолокація лише за натисканням кнопки
- Адаптивний інтерфейс: бокова панель на ПК, розгортна нижня панель на смартфоні
- Світла й темна теми, український інтерфейс

## Встановлення та запуск

Потрібен **Node.js 18+** (перевірено на Node 24).

```bash
npm install
npm run dev
```

Відкрийте http://localhost:5173.

Інші команди:

```bash
npm run build     # перевірка типів + продакшн-збірка в dist/
npm run preview   # локальний перегляд продакшн-збірки
npm run typecheck # лише перевірка TypeScript
```

API-ключі не потрібні — усі використані сервіси безкоштовні й публічні.

## Джерела даних і їх обмеження

| Що | Джерело | Примітки |
|---|---|---|
| Картографічна основа | [OpenStreetMap](https://www.openstreetmap.org/copyright) тайли | © учасники OpenStreetMap, ODbL |
| Парковки, зарядки | [Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API) | Теги `amenity=parking`, `amenity=parking_space`, `amenity=charging_station` |
| Приблизна адреса, пошук вулиць | [Nominatim](https://nominatim.org/) | Лише за дією користувача, ≤ 1 запит/с |
| Маршрути | Google Maps / OSM (fossgis OSRM) | Відкриваються у зовнішньому сервісі |

**Важливо:**

- OpenStreetMap наповнюють волонтери. Дані можуть бути **неповними або застарілими**.
- Наявність парковки на карті **не означає**, що там зараз є вільне місце. Відкритих даних про зайнятість паркомісць у Львові немає, тому застосунок показує «Фактична зайнятість невідома».
- Статус зарядних станцій (вільна / зайнята / не працює) у OSM відсутній — показується «Статус невідомий».
- Відсутність тегу не трактується як відсутність характеристики: якщо, напр., `fee` не вказано, показуємо «Оплата невідома», а фільтр «Безкоштовні» включає лише об'єкти з явним `fee=no`.
- Тарифи показуються лише якщо в OSM заповнено тег `charge`, з позначкою «Тариф у джерелі».
- Адреса без тегів `addr:*` визначається за координатами через Nominatim і позначається як приблизна.
- Кожна картка має посилання на об'єкт в OpenStreetMap — помилку можна виправити безпосередньо там.

### Які теги читаються

- **Парковки:** `name`, `addr:*`, `parking` (surface, underground, multi-storey, street_side, lane…), `fee`, `charge`, `capacity`, `capacity:disabled`, `opening_hours`, `access`, `wheelchair`, `maxstay`, `operator`, `website`.
- **Зарядки:** `name`, `operator`, `brand`, `network`, `socket:*` (type2, type2_combo → CCS2, chademo, type1, type1_combo → CCS1, tesla_*, gb_t, schuko…), `socket:*:output`, `charging_station:output`, `maxpower`, `capacity`, `fee`, `charge`, `opening_hours`, `access`.

### Публічні сервери Overpass і навантаження

Overpass — безкоштовний сервіс з обмеженнями. Застосунок:

- завантажує дані для Львова одним запитом, а для інших місць — лише за кнопкою «Шукати в цій області» (з масштабу ≥ 12 і для областей не більших ~40×40 км);
- кешує результати в пам'яті та в LocalStorage на 6 годин (до 4 областей);
- якщо сервер недоступний, показує збережену копію з датою й позначкою;
- не надсилає запити частіше ніж раз на 4 секунди;
- пробує кілька інстансів: якщо перший не відповідає 8 с або повертає помилку, паралельно запитує наступний, а зайві запити скасовує;
- показує зрозумілу помилку з кнопкою «Повторити».

Публічні інстанси іноді перевантажені (502/504/таймаути). Якщо дані не завантажуються — зачекайте кілька хвилин і натисніть «Повторити».

## Підключення іншого джерела даних

Реалізуйте інтерфейс `LocationProvider` з `src/services/dataSource.ts`:

```ts
export interface LocationProvider {
  readonly name: string;
  fetchLocations(bbox: BBox, signal?: AbortSignal): Promise<LocationResult>;
}
```

і замініть `locationProvider` в кінці `src/services/overpassApi.ts`. Так можна підключити офіційні API операторів зарядних станцій або міської системи паркування для реальної зайнятості, тарифів і статусів. Ключі таких API **не можна** зберігати у фронтенді — потрібен власний серверний проксі.
